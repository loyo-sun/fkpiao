## 为什么做这个工具

纸质报销很麻烦。

电子发票、高铁票和各种 PDF 票据需要逐张打开、调整大小、复制排版，再组合到 A4 纸上打印。票据一多，不仅操作重复，还很容易出现比例不一致、内容被裁切或漏放的问题。

**发克票**把这些步骤合并成了一次操作：批量导入 PDF 票据，工具会自动按照每张 A4 上下两张的方式等比缩放、分页预览并生成排版后的 PDF。确认无误后直接下载打印即可。

## 功能

- 批量导入多个 PDF 票据
- 自动识别普票、专票、火车票和高铁票，低置信度结果可手动纠正
- 可分别配置各类票据的导出份数
- 自动按 A4 上下两张进行双拼排版
- 保持原始比例，避免票据信息裁切
- 支持多页预览和翻页检查
- 支持彩色、黑白两种导出模式
- PDF 生成后自动下载，也可手动再次下载
- 票据解析、预览和 PDF 生成均在浏览器本地完成

## 发票识别

工具优先读取 PDF 自带的文本层，通过票据标题、铁路客票特征和车次等规则识别普票、专票、火车票和高铁票，并提取发票金额。识别结果会显示在发票列表中，低置信度的类型可由用户手动修正。

仅当本地规则无法确认发票类型或金额时，系统才调用 Vercel API 兜底。优先发送截断后的文本；无文本层的扫描件只发送压缩后的第一页。未配置 API Key 或 AI 不可用时，系统会回退到人工确认，不影响本地排版和导出。

## 本地运行

```bash
npm install
npm run dev
```

建议使用 Node.js 20.19 或更高版本。

## 构建

```bash
npm run build
```

构建结果位于 `dist-vercel` 目录。项目已包含 `vercel.json`，可直接导入 Vercel，或在项目目录执行 Vercel CLI 部署。

## 隐私说明

PDF 的读取、预览、排版和导出均在浏览器内完成。只有本地无法确认发票类型或金额时，必要的截断文本或压缩后的第一页图像才会发送到云端 AI；原始 PDF 文件不会作为完整文件上传。

## Vercel 配置

在 Vercel 项目中设置 `OPENAI_API_KEY`，并按需设置 `OPENAI_BASE_URL` 和 `OPENAI_INVOICE_MODEL`。当前默认地址为 `https://api.openai-hub.net/v1`，默认模型为 `gpt-5.6-luna`。密钥只存在于 Vercel 服务端环境变量，绝不能放进前端代码或提交到 Git。没有配置密钥时，本地发票识别、排版和导出仍可使用。
